# CodeAlpha_Task3_Automation
CodeAlpha Task 3: Task Automation with Python

Project Overview

This project automates the task of moving JPG image files from one folder to another using Python.

Features

- Detects JPG files in the source folder.
- Creates the destination folder automatically.
- Moves JPG files using Python.
- Displays the total number of files moved.

Technologies Used

- Python
- os module
- shutil module

How to Run

1. Install Python.
2. Create an "images" folder in the project directory.
3. Place JPG images inside the "images" folder.
4. Run the program:

python task3.py

Output

Displays the names of moved files and the total number of files moved.
